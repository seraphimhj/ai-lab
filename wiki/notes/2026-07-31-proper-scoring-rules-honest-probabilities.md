命中薄弱点：*统一数学框架*；同时推进*模型评估*主线——今天承接昨天的 calibration，把 NLL 与 Brier score 放进 proper scoring rule（适当评分规则）这一套“怎样奖励诚实概率”的统一框架。

# 伴读：谁能让模型诚实地报出概率？

> 材料切面：proper scoring rules、log score 与 Brier score。不是罗列指标，而是追问：如果真实概率藏在模型心里，评测者只看见一次结果，怎样设计计分规则，使模型没有撒谎的收益？

## 全局地图

### 一句话摘要

适当评分规则的核心不是“预测对了加几分”，而是设计一种激励：无论真实概率是多少，模型在长期期望上都以如实报告自己的概率信念为最优策略；NLL 与 Brier 是两种不同性格、却共享这条原则的实现。

### 结构地图

```text
不可直接观察的真实信念 q
            |
            | 模型报告 p
            v
      评分规则 S(p, y) <----- 现实只揭晓一次结果 y
            |
            v
  在 y ~ q 下计算长期期望损失
            |
            +--> 若 p=q 最优：proper（适当）
            |
            +--> 若只有 p=q 唯一最优：strictly proper（严格适当）

两种实现：

log loss   ------> 比较概率分布的对数差 ------> excess risk = KL
Brier loss ------> 比较概率向量的平方距离 ----> excess risk = squared distance
```

### 段落分类概览（Agent 判断）

- [骨] 第一单元：从“预测对错”转向“报告概率是否诚实”。
- [肌] 第二单元：用天气预报说明单次结果为何不能审判单个概率。
- [骨] 第三单元：推导 Brier loss 为什么让如实报告成为唯一最优解。
- [骨] 第四单元：推导 log loss 与 KL、MLE 的同源关系。
- [肌] 第五单元：比较两种规则的性格，而不是争论谁绝对更好。
- [骨] 第六单元：指出 proper 只保证激励正确，不保证评测已经可靠。

## 逐段伴读

### 第一单元 [骨]：评概率，不是在评一次猜中没有

*English anchor*

> A scoring rule is proper if a forecaster minimizes expected loss by reporting the probability distribution it actually believes.
>
> 如果预测者如实报告自己相信的概率分布，能够使其期望损失最小，那么这条评分规则就是适当的（proper）。

昨天我们说：准确率、AUC 与校准不是一回事。今天再往下一层：为什么 NLL 或 Brier 有资格评概率？

答案不是因为它们“常用”，而是因为它们解决了一个机制设计问题：

```text
评测者想要：模型报告它真正相信的 q
模型可以做：选择任意报告 p
评测者能观察：最终结果 y
评分规则要保证：说真话 p=q，比夸大或缩小把握更划算
```

这里的 q 不是世界终极真相，而是预测者基于当前信息形成的条件信念。例如模型看完病历后认为患病概率为 0.7；评测者无法打开模型直接读取这个“0.7”，只能看到它报了什么，以及病人最后是否患病。

所以 proper scoring rule（适当评分规则）本质上是一份*激励相容的概率合同*：你可以撒谎，但从长期期望看，撒谎不会占便宜。

*结构标注*：核心概念。把评测指标提升为“如何诱导诚实报告”的机制设计问题。

*概念状态判断*：最容易处在“理解了指标公式，却不知道为什么重要”。公式只是表面，真正被统一的是背后的激励原则。

*先问*：如果一个模型真实相信答案正确率是 70%，产品却只奖励“置信度超过 90% 且答对”的样本，它会学会更准确，还是学会更大胆地报数？

### 第二单元 [肌]：30% 下雨，今天没下，预报错了吗？

天气预报说“明天下雨概率 30%”，第二天没有下雨。不能仅凭这一次结果宣布预报错误。30% 本来就允许多数时候不下雨。

同样，预报 90% 下雨而当天真下了，也不能仅凭一次命中证明 90% 是准确的。一个永远报 99% 的人，在碰巧下雨的那天也会显得神准。

概率预测必须放在重复事件或相似样本的集合里评估：

```text
所有报告 0.3 的场合
        |
        +--> 长期约 30% 发生：可能校准
        |
        +--> 长期约 80% 发生：系统性低估
```

但只检查频率还不够。一个模型对所有事件都报总体基础率，也可能总体校准，却完全不利用个体信息。评分规则需要同时处理两件事：

1. 不能奖励虚假的自信；
2. 也不能让永远躲在模糊的基础率里占便宜。

*结构标注*：直觉铺垫。解释为何单样本的“对/错”不足以审判概率报告。

以上一段在支持第一单元的“长期期望”视角。

## 第三单元 [骨]：Brier loss 为什么奖励诚实？

二分类时，设结果 y 只能取 0 或 1，模型报告事件发生概率 p。Brier loss 是：

```text
L_Brier(p, y) = (p - y)^2
```

假设模型真正相信事件发生概率是 q。那么在它自己的信念下：

```text
事件以概率 q 发生，损失为 (p-1)^2
事件以概率 1-q 不发生，损失为 p^2
```

因此期望损失为：

```text
E[L_Brier]
= q(p-1)^2 + (1-q)p^2
= (p-q)^2 + q(1-q)
```

最后一行最重要。它把损失拆成两部分：

```text
(p-q)^2     你报告失真的代价；只有 p=q 时为 0
q(1-q)      事件本身不可消除的不确定性；与报告 p 无关
```

模型控制不了第二项，只能控制第一项。因此唯一最优选择就是 p=q：如实报告。

这不是一句道德劝告，而是平方损失的代数结构把“诚实”变成了最优策略。只要模型试图把 0.7 夸成 0.9，或缩成 0.5，都会多付一笔与报告偏差平方成正比的期望代价。

*结构标注*：第一条核心推导。展示 strictly proper 的“唯一最优”从哪里来。

### 一束侧光：这和回归中的偏差-方差分解是同一个形状

这里的结构与平方误差回归很像：预测值偏离条件均值的部分可以被优化，而结果围绕条件均值的随机波动不能被预测器消除。

```text
概率预测：报告 p 偏离真实信念 q  ---> 可避免的平方代价
回归预测：预测 a 偏离条件均值 E[Y|X] ---> 可避免的平方代价
```

平方损失之所以在回归中“追向条件均值”，与 Brier loss 在二分类中“追向真实概率”，不是巧合。因为二元变量的条件均值本身就是：

```text
E[Y|X] = P(Y=1|X)
```

这里的论证结构，和监督回归是同一个形状：*平方损失会把预测拉向条件均值；对 0/1 结果而言，条件均值恰好就是概率。*

### 碰撞

作者最想让你接受的点是：*Brier 不只是“概率版 MSE”，它通过期望风险分解，让诚实报告成为唯一最优策略。*

压力测试：如果有人反驳，“现实中同一个 x 不会重复出现，所谓真实 q 根本无法观察，所以这套证明没有实际意义”，你会怎样回应？

一个可供校验的回应是：我们确实不能逐样本观察 q；properness 是总体激励保证，不是逐样本验真术。实际评测仍要依赖样本来自近似相同的数据生成过程，并借助足够样本、分组、切片和不确定性估计来逼近期望。这条反驳没有推翻评分规则，却击中了*有限样本评测*的边界。

## 第四单元 [骨]：log loss 为什么把 MLE、交叉熵与 KL 接起来？

*English anchor*

> The logarithmic score is strictly proper, and its expected excess loss is a Kullback-Leibler divergence.
>
> 对数评分是严格适当的；它相对于诚实报告多出的期望损失，正是一个 KL 散度。

二分类 log loss，也就是 NLL：

```text
L_log(p, y) = -[y log p + (1-y) log(1-p)]
```

若真实信念为 q，报告为 p，期望损失是：

```text
E[L_log]
= -q log p - (1-q) log(1-p)
= H(q) + KL(Bernoulli(q) || Bernoulli(p))
```

再次出现同样的两部分：

```text
H(q)       世界在给定信息下剩余的不确定性；模型无法靠改口消除
KL(q||p)   报告 p 偏离信念 q 的额外代价；只有 p=q 时为 0
```

于是统一关系变得非常清楚：

```text
训练视角：最小化样本 NLL
     |
     +--> 等价于最大化观测数据似然（MLE）
     |
总体视角：最小化期望交叉熵
     |
     +--> 等价于最小化 H(q) + KL(q||p)
     |
激励视角：KL 只有在 p=q 时为 0
     |
     +--> 如实报告是唯一最优策略（strictly proper）
```

MLE、NLL、交叉熵、KL、proper scoring rule 并不是五件互不相干的工具。它们是同一对象在不同问题下的名字：

- MLE 问：参数怎样让观测数据更可能？
- NLL 问：优化器要最小化什么样本损失？
- 交叉熵问：真实分布与预测分布的平均编码代价是什么？
- KL 问：错误报告比诚实报告多付多少分布失配代价？
- properness 问：这套代价是否让说真话成为最优策略？

*结构标注*：第二条核心推导。把用户的“统一数学框架”薄弱点接到概率评测。

*先问*：如果训练集 NLL 很低、测试集 NLL 很高，问题是“评分规则不适当”，还是模型没有在新分布上学到 q？为什么这两个诊断不能混为一谈？

### 最强反驳：真实标签往往也不是“真相”

医疗标签可能来自有噪声的诊断流程；偏好标签取决于标注者；LLM-as-judge 还会带着自身偏差。此时 log loss 仍会诚实地诱导模型逼近*标签生成分布*，但那个分布未必是我们真正关心的目标。

```text
proper scoring rule 保证：p 追向观测标签的条件分布
它不保证：观测标签的条件分布就是业务真相
```

这正是端到端闭环中的关键边界：目标一旦错了，优化越成功，模型可能越稳定地学错。

## 第五单元 [肌]：NLL 与 Brier，差别不在“谁更科学”

两者都严格适当，却对错误有不同性格。

### 5.1 对极端自信错误的态度

```text
真实 y=1，而模型报告 p 趋近 0：

log loss   = -log(p)       会持续增大，没有有限上界
Brier loss = (p-1)^2       有上界，惩罚更温和
```

因此 NLL 对“把真实结果说成几乎不可能”极其敏感。它适合在概率质量分配上追究极端自信，但也可能被少数异常标签、标注错误或数值问题强烈影响。

Brier 更平滑、更容易解释，并能做 calibration / resolution 一类分解；但它不会像 log loss 那样猛烈区分“很错”和“自信到离谱地错”。

### 5.2 多分类时看什么

多分类 Brier loss 比较整条概率向量与 one-hot 结果的平方距离；log loss 主要通过真实类别获得的概率来计分。二者都看完整概率报告，而 accuracy 只看 argmax。

```text
预测 A：[0.51, 0.49, 0.00]
预测 B：[0.99, 0.01, 0.00]
真实类：第一类

accuracy：都算对
proper score：会区分概率承诺的强弱
```

但若真实类变成第二类，B 的自信错误会受到更重惩罚，尤其在 log loss 下。

### 5.3 选择规则其实是在选择风险敏感度

因此不要问“哪个指标绝对最好”，而要问：

- 是否特别在意极端自信错误？
- 标签噪声是否可能制造离群损失？
- 是否需要可分解的诊断？
- 下游行动是否对概率区间有非线性代价？

严格适当保证的是*诚实方向*；具体评分规则决定的是*偏离诚实时，不同方向和幅度的错误如何收费*。

*结构标注*：比较证据。说明同属一个数学家族，不等于行为完全相同。

以上三段在支持第四单元：统一框架保留了共同原则，也允许不同风险性格。

## 第六单元 [骨]：proper 不是“评测已经万无一失”

proper scoring rule 很强，但它只解决一个局部问题：给定目标分布与期望，什么报告最优。它没有自动解决以下问题。

### 6.1 有限样本

理论说的是期望风险，评测拿到的是有限样本平均。小切片上，一个更好的概率模型可能暂时得到更差分数。因此应报告置信区间、重复实验或 bootstrap，而不是把微小分差当成确定结论。

### 6.2 分布漂移

模型在验证分布上诚实，不代表上线后仍然诚实。基础率改变、用户选择改变、数据采集策略改变，都可能让 q 变化。

### 6.3 选择性预测

LLM 系统会拒答、调用工具或只在部分问题上给出答案。若只给“选择回答”的样本计分，系统可能通过挑容易题改善分数。此时必须把 coverage（覆盖率）与 risk（风险）一起看。

### 6.4 奖励黑客与代理目标

当评分规则成为训练目标，模型会优化可见规则。若标签、judge 或采样流程只是目标的代理，properness 无法阻止模型忠实地钻代理目标的空子。

```text
评分规则 proper
      |
      +--> 报告对“被评分的标签分布”诚实
      |
      -X-> 标签无噪声
      -X-> 数据与线上同分布
      -X-> 下游决策效用最大
      -X-> 系统不会利用评测漏洞
```

*结构标注*：边界条件。把数学保证放回数据、采样、评测、上线的端到端闭环。

*碰撞提问*：作者这段最想说服你接受的点是——*一个指标可以在数学上完全正确，却在系统层面回答错问题。* 你当前最信任的离线指标，它默认了哪个最脆弱的条件：标签可信、样本同分布，还是选择机制不作弊？

## 一套可执行的评测顺序

```text
1. 明确被预测的随机变量
   “答案正确”由谁定义？标签怎样产生？

2. 明确概率语义
   p 是类别概率、成功概率、judge 同意概率，还是未经校准的分数？

3. 选严格适当评分规则
   NLL：重视完整分布，强罚极端自信错误
   Brier：平方距离平滑，便于分解与解释

4. 同时报区分与校准
   排序指标 + proper score + reliability diagram

5. 展开关键切片
   时间、语言、领域、难度、长尾实体、工具调用与否

6. 若允许拒答
   同时报 risk-coverage curve，禁止只看已回答样本

7. 接入真实行动代价
   检查更好的概率分数是否真的改善阈值决策

8. 上线后重估
   监控基础率、标签延迟、选择偏差与 calibration drift
```

## 全文复盘

### 理解轨迹

```text
“模型报 0.7，可信吗？”
          |
          +--> 不能用一次成败审判概率
          |
          +--> 要在真实信念 q 下看长期期望
          |
          +--> Brier excess risk = (p-q)^2
          |
          +--> Log excess risk   = KL(q||p)
          |
          +--> 二者都让 p=q 唯一最优
          |
          +--> 但只对目标标签分布作保证
          |
          +--> 有限样本、漂移、选择与代理目标仍需另查
```

今天要带走的不是两个公式，而是一条判断线：

```text
好指标 = 正确的激励性质 + 正确的目标分布 + 正确的采样方式 + 正确的决策连接
```

缺任何一项，“数学上 proper”都可能变成“系统上答非所问”。

### 读后一句话（不可跳过）

读完后，你最想对这套框架说的一句话是什么？不要复述“Brier 是平方误差、NLL 是对数损失”；请直接指出：在你正在做的模型或 RAG 系统里，模型报告的 p 究竟是在逼近哪个 q，而那个 q 真的是业务关心的对象吗？

### 终局问题

如果一个奖励模型能被 proper scoring rule 训练得非常“诚实”，但它诚实表达的只是标注者群体的偏好分布，那么我们得到的是更可靠的价值判断，还是更精确的人群意见测量仪？当“真相”本身由反馈过程生成时，properness 应该相对于谁来定义？
