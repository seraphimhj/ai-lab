# DAgger 之后为什么是 RL：把训练分布直接做成部署分布，而不是去追它

> 本次命中：**端到端闭环 + 统一数学框架 + retrieval 以外·后训练**。承接 08-14（Teacher Forcing 的 exposure bias）与 08-15（Scheduled Sampling / DAgger）的分布错位主线，回答那条线结尾留下的问题：模仿学习的终点为什么不是更聪明的模仿，而是换一个锚。

## 全局地图

### 一句话摘要

08-14/15 的病是「训练时模型看的历史 ≠ 上线时模型看的历史」；DAgger 的修法是让*数据分布*去追*策略访问的状态*（on-policy 采状态、专家重标动作），但监督信号仍是「模仿专家」——天花板被钉死在专家水平，且要求专家随叫随到；RL 换掉锚：不再模仿任何分布，而是在策略自己采样的分布上直接优化回报——「训练分布 = 部署分布」这个条件第一次被*直接*满足，代价是三本新账：稀疏回报的信用分配、必须随身携带的 KL 信任域、on-policy 的采样成本。

### 结构地图

```text
08-14：训练用专家历史，上线用模型历史  ->  exposure bias
  |
  v
08-15：DAgger —— 让「数据分布」追上「策略访问的状态」
        监督信号不变：模仿专家在那里的动作
        所以天花板 = 专家，且要随时问得到专家
  |
  v
今天：换锚 —— 目标从「贴近某个分布」变成
      「在策略自己的分布上最大化回报」
      on-policy：训练采样分布 == 部署分布（闭环直接接通）
      |
      +--- 代价账 1：稀疏回报 -> 信用分配   （接 08-02）
      +--- 代价账 2：目标变了 -> KL 信任域  （接 08-13）
      +--- 代价账 3：每轮重采样 -> 旧数据重用的诱惑与 IS 方差（接 08-12）
```

## 1. [骨] 上一剂药治好了什么，没治好什么

08-15 结尾我们停在 DAgger：让当前策略去访问状态，再向专家询问"这个状态该做什么"，把聚合数据反复重训，直到训练分布追上部署分布。

先准确说出 DAgger 治好了什么：它把*数据来自哪里*这一环修好了。行为克隆的病灶是"只在专家走过的路上训练"，DAgger 改成"在你（策略）会走到的路上训练"。这是数据侧的 on-policy 化。

但请注意它的监督信号那一行没有变：还是"专家在这个状态的动作"。于是 DAgger 隐含了两个前提：

*前提一：专家随叫随到。* 每一步 rollout 都要有人标注"正确的下一步"。在模拟器里可以（查询一个更强策略或真值），在真实环境里，每次失败都要人类重标，成本随 horizon 线性涨。

*前提二：专家的水平就是天花板。* 损失函数在把策略往专家方向推。策略可以学会专家会做的事，但不可能系统性地比专家更好——因为它从来没被奖励过"比专家好"这件事。

*结构标注：边界刻画。这一节不是否定 DAgger，而是把它的成功条件写清楚，为下一节的换锚做铺垫。*

## 2. [骨] 换锚：不模仿分布，而是直接优化策略自己的分布

RL 的转向可以用一句话说：*把"目标分布"这个词从损失里删掉。*

行为克隆（BC）和 DAgger 的损失都长这样：

```text
max  E_{ (x,y) ~ D }  log π_θ(y|x)
```

期望落在数据分布 D 上，目标是把 π_θ 拉向 D。D 是外部给定的——专家轨迹（BC）或专家重标后的策略状态（DAgger）。模型永远在*追一个外部分布*。

RLHF/PPO 的目标换成了：

```text
max  E_{ y ~ π_θ }  r(x,y)   -   β · KL(π_θ ‖ π_ref)
      ^^^^^^^^^^^^             ^^^^^^^^^^^^^^^^^^^^^^
      期望落在策略自己     KL 锚住参考分布（08-13 的信任域）
      采样的分布上
```

这一行里发生了两件大事：

*第一件：期望的分布从 D 换成了 π_θ。* 梯度里要估计的量是 `E_{y~π_θ}[∇log π_θ(y|x) · A(x,y)]`，期望落在*当前策略*的采样分布上——这正是 08-15 说的"部署分布"。也就是说，训练时采样什么，就优化什么，上线时也是这个分布来采样。**"训练分布 = 部署分布"不是靠数据重标去追出来的，而是目标函数的结构直接保证的。**

*第二件：监督信号从"专家动作"换成了"回报"。* 模型不再问"专家会怎么做"，而问"我做的这个动作，环境给了多少回报"。天花板从专家水平换成回报本身——这意味着策略*可以*超过专家，因为优化的不是与专家的距离，而是回报。

这就是 AlphaGo 那条路线的数学形态：先用人类棋谱做 BC（模仿），再上 RL 自我对弈（优化回报），最后超过所有人类棋谱。BC 负责起步，RL 负责越过专家。

*结构标注：核心论点。整篇的支点：换锚 = 换期望所在的分布 + 换监督信号的来源。*

---

*碰撞提问（先想再往下）*：这一节最想让你接受的一点是——"DAgger 是间接追分布，RL 是直接造分布"。你接受这个区分吗？如果不接受，你觉得 DAgger 和 RL 之间是断层，还是一条连续的光谱？（光谱的说法确实有人支持：DAgger 里"专家动作"可以看成一种特殊的、状态相关的奖励；RL 里 KL 正则也可以看成一种"参考分布"在拉你。但有一个不可调和的分歧：DAgger 的标签来自外部专家，RL 的回报来自环境，而**环境不会因为状态是模型自己造成的就拒绝给回报**——这正是 RL 能处理"策略诱导分布"而模仿不能的根源。）

## 3. [肌] 代价账 1：稀疏回报与信用分配（接 08-02）

期望落在 π_θ 上，是这份礼物最贵的部分——因为回报是稀疏的：一次工具调用循环，几十上百个 token，只有一个最终成败信号。而梯度 `∇log π_θ(y|x) · A` 要把这一个数分摊到每一个 token 上。

这就是 08-02 讲过的信用分配（credit assignment）：*一条序列的总奖励，如何分摊到各个 token 的学习权重上。* 方法差异全在这：

```text
REINFORCE：整条轨迹的回报原样乘到每个 token 的梯度上（方差巨大）
PPO：advantage A = 回报 - 基线，用 critic 估计基线降方差，clip 限幅
GRPO：组内相对——同一个 prompt 采 k 个回答，用组内排名/相对奖励当 A，
      不需要 critic（08-02 已展开）
```

方差是 on-policy 的天然税：期望在 π_θ 下，而 π_θ 每更新一步就变，上一轮的样本立刻过期；同一条轨迹里的 token 高度相关，分摊又放大噪声。批评者常说的"PPO 不稳定"，大部分方差就来自这里——不是 PPO 的 clip 写错了，而是"在策略自己的分布上求期望"这件事本身贵。

*结构标注：证据展开，支撑第 2 节的核心论点——换锚的代价之一。*

## 4. [肌] 代价账 2：KL 信任域在 RL 里为什么不是装饰（接 08-13）

08-13 我们把 KL 正则读成"分布空间里的信任域"：β 决定模型能用多少分布漂移去交换奖励。今天补上另一半：*为什么 MLE/BC 不需要这个装置，而 RL 必须带？*

因为两者的目标函数性质不同：

- BC 的目标是分布本身。`max E log π_θ` 每走一步，π_θ 都在靠近数据分布——目标自带"你去哪"的信息，漂移方向被数据钉住。
- RL 的目标是回报。`max E r` 只告诉你"哪里更高"，不告诉你"哪里不能去"。如果没有 KL 锚，策略可以一路滑向回报函数的漏洞区（reward hacking）——而回报函数本身是近似物（08-01 讲过：LLM-as-judge / reward model 是会被迎合的指南针）。

所以 KL 在 RL 里承担两个角色：一个是*信任域*（别走太远，远了估计就不准了），一个是*支持度保障*（π_ref 覆盖的分布区域，就是模型"还会说人话"的区域）。MLE 不需要它，是因为 MLE 的目标分布本身就覆盖"会说人话"的区域；RL 的目标里没有这个信息，必须外挂。

这也能解释一个常见困惑：为什么 SFT 里没人讨论 KL 惩罚，DPO 里 KL 却藏在 loss 里、PPO 里显式出现——因为三者距离"纯回报优化"的远近不同，需要的外部锚的强度就不同。

*结构标注：证据展开，支撑核心论点——换锚的代价之二。*

## 5. [骨] 统一收口：三行式子，一根轴

把这条线的三个方法并排（这是 08-02/08-12/08-13 一直在攒的统一数学框架的收口）：

```text
BC     : max  E_{x,y~D}          log π_θ(y|x)             目标=贴近数据分布（前向 KL）
DAgger : max  E_{x,y~D_π}        log π_θ(y|x)             目标没换，数据换成策略诱导分布
RLHF   : max  E_{y~π_θ}[r(x,y)] - β KL(π_θ‖π_ref)         数据没换（策略自采），目标换了
```

一根轴：*监督信号来自外部分布（专家/数据），还是来自环境回报（策略自己的轨迹）？* 沿这根轴，DAgger 和 RL 的差别不在"数据是否 on-policy"（两者都 on-policy 化了），而在**"谁定义什么是对的"**。

再往深一层，看梯度形态，会发现 08-15 的病在目标函数层的投影：

```text
∇J = E_{ y ~ π_θ } [ ∇log π_θ(y|x) · A(x,y) ]
```

期望在 π_θ 下。如果图省事，用旧策略 π_old 留下的数据来估计这个期望——那就是**梯度层的 covariate shift**：期望算在 π_old 上，梯度却要更新 π_θ。08-12 的 importance sampling 给出修正：乘上权重 π_θ/π_old，但权重随分布距离指数爆炸，方差失控；PPO 的 clip 就是在"修正偏差"和"压住方差"之间的工程折中。

于是三天前到今天的线索在这里合拢：

```text
08-14  exposure bias  = 条件分布错位（推理层）
08-15  DAgger         = 数据侧追分布（采样层）
08-12  importance weight = 分布不匹配时的修正器，但方差是它的税
今天    on-policy RL = 不修正，直接让期望落在正确的分布上
```

"为什么 PPO 需要 on-policy（或带 clip 的近似）"不是一个工程细节，而是统计一致性要求：**你要优化的期望在哪个分布下，数据就必须从那个分布来**——这跟 08-15 里"统计一致性"是同一个词，同一个要求。

一个值得玩味的退化演示（数学上严格、直觉上锋利）：如果奖励函数恰好取 `r(x,y) = β·log(p_data(y|x)/π_ref(y|x))`，RLHF 目标就变成 `-β·KL(π_θ ‖ p_data)`——反向 KL，让 π_θ 去匹配数据分布，但方向与 BC 相反。BC 是前向 KL（数据→模型，mode-covering，模型要覆盖数据的每个模式）；这个特例是反向 KL（模型→数据，mode-seeking，模型只聚焦最高质量的模式）。同一个"分布匹配"的骨架，方向相反，行为迥异——这大概是最干净的一个例子，说明"统一数学框架"不是把方法抹平，而是把差异精确定位到*一个参数*上。

*结构标注：全篇枢纽。把三天的线索在梯度形态上收口，回接 08-12/08-15。*

## 6. [筋] 工程落点：什么时候停在 DAgger，什么时候必须上 RL

从这一节往回收，落到选择：

*留在 DAgger 的条件*：专家便宜（可重标、可查询）、状态可复现（模拟器/沙箱）、失败代价高（08-15 的护栏语境——付款、删库这类动作）。此时 RL 的方差税不值得交。

*必须上 RL 的条件*：回报可算但专家不可得（动作空间太大、人类标注不过来）、或者任务要求*超过*专家（下棋、写代码的某些维度、机器人控制）。注意 RL 的前提是回报函数可信——08-01 的提醒在这里回响：reward model 自己也会被迎合，闭环里评测这一环又转回来了。

*结构标注：过渡与决策框架。*

---

*碰撞提问（核心）*：这条推理线最想说服你接受的一个点是——**"训练分布 = 部署分布"是统计一致性的要求，DAgger 是间接追它（重标数据），RL 是直接造它（期望落在 π_θ 上）**。你接受吗？

- 如果你接受：压力测试——"RL 的 on-policy 也是近似的：π_θ 每步都在变，老样本立刻过期，PPO 的 clip 就是在允许一定程度用旧分布。这不就是 RL 版的 Scheduled Sampling 吗？"你怎么回应？*（提示：clip 的限幅范围和 β 的信任域共同定义了"允许偏离多远"，这与 Scheduled Sampling 无原则地混数据有本质区别——前者的偏离是被目标函数显式定价的，后者的偏离是隐式的、不可控的。）*
- 如果你不接受：不舒服出现在哪一句？是"天花板 = 专家"这个说法（也许你认为 DAgger 多次迭代可以涌现超专家行为），还是"RL 直接满足分布一致"（也许你认为 on-policy 采样在工程上从未真正实现）？

### 读后一句话（不可跳过）

请在心里完成这一句，不要复述"训练分布要等于部署分布"：

> *读完这篇之后，你最想对这条推理线说的一句话是什么？*

更值得写的是你的判断：你是否相信"期望落在策略自己的分布上"这一行数学，在真实工程里真的兑现过——还是说，它只是让误差换了一个更隐蔽的位置？（比如 reward model 的偏置，08-01 说的那个被迎合的指南针。）

### 终局问题

> 如果"训练分布 = 部署分布"是统计一致性的要求，而 RL 用"期望落在 π_θ 上"直接满足它——那么当部署环境本身会变化（用户分布漂移、工具版本升级）时，**训练和部署的"同一性"锚在哪个时间点上才算数？**

这不是修辞问题。它把 08-14 的 exposure bias、08-08 的离线评估失效、08-01 的 reward 偏移接到同一个难题上：分布一致是一个瞬间的快照，而线上是一个持续漂移的过程。
