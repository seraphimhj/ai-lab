# PPO 的 clip 到底剪掉了什么？——旧策略数据、重要性比率与一笔有意为之的偏差

> 本次命中：**统一数学框架 + 端到端闭环 + retrieval 以外·后训练**。承接 08-16 留下的开口：on-policy 数据在策略更新后立刻“变旧”，PPO 如何用 importance ratio 重用它，又为何主动把无偏估计剪成有偏估计。

## 全局地图

### 一句话摘要

PPO 的 clip 不是“防梯度爆炸”的通用技巧，而是一份局部数据使用合同：用旧策略采到的数据估计新策略目标时，重要性比率负责纠正分布错位；但当新旧策略差得太远，正确修正会产生巨大方差，于是 clip 主动放弃一部分无偏性，只保留那些仍能被旧数据可信支持的更新——它剪掉的不是概率本身，而是**旧数据对过远新策略的发言权**。

### 结构地图

```text
当前策略 pi_old 采样轨迹
        |
        v
数据分布固定在 pi_old
        |
        | 想用同一批数据更新 pi_theta 多轮
        v
目标却属于 pi_theta
        |
        +--> 直接用：分布错位，梯度估错
        |
        +--> 乘 ratio = pi_theta / pi_old：理论纠偏
                         |
                         +--> ratio 极端：少数样本支配，方差爆炸
                                      |
                                      v
                           PPO clipped surrogate
                           只阻止“有利方向上的过度更新”
                                      |
                         +------------+------------+
                         |                         |
                    得到稳定复用                  付出偏差
                    但不是无限复用                也不等于 KL 约束
```

## 1. [骨] 数据为什么刚采完就开始过期

08-16 把策略梯度写成：

```text
g(theta)
= E_{a ~ pi_theta(.|s)} [
    grad log pi_theta(a|s) * A(s,a)
  ]
```

关键不只在梯度，而在期望下标：动作应当来自正在优化的 `pi_theta`。

但真实训练不可能每改一个参数就重新 rollout。通常流程是：

```text
1. 冻结一份策略 pi_old
2. 用 pi_old 采一批回答/轨迹
3. 在同一批数据上做多个 minibatch、多个 epoch 的更新
4. 丢掉旧数据，用新策略重新采样
```

第一步更新前，`pi_theta = pi_old`，数据完全匹配。更新一次后，`pi_theta` 变了，数据却还来自 `pi_old`；再更新几轮，差距继续扩大。

这和 Teacher Forcing 的 exposure bias 是同一种结构，却发生在不同层：

```text
Teacher Forcing：训练条件历史来自专家，部署历史来自模型
PPO 数据复用   ：训练样本来自旧策略，目标期望属于新策略
```

共同病灶都是：**你在哪个分布下求期望，就应从哪个分布取样。** 数据没有神秘地“失效”；失效的是它对另一个分布的代表性。

*结构标注：核心问题定位。PPO 的起点不是 clip，而是同一批 rollout 被重复使用时出现的策略分布错位。*

## 2. [骨] Importance ratio：给旧样本换一个新分布的权重

如果样本来自 `pi_old`，却想计算 `pi_theta` 下的期望，08-12 的 importance sampling（重要性采样）给出精确换元：

```text
E_{a ~ pi_theta}[f(a)]
=
E_{a ~ pi_old}[
  pi_theta(a|s) / pi_old(a|s) * f(a)
]
```

定义 probability ratio（概率比）：

```text
r_t(theta)
= pi_theta(a_t|s_t) / pi_old(a_t|s_t)
= exp(log pi_theta(a_t|s_t) - log pi_old(a_t|s_t))
```

它不是奖励。它回答的是：**这次实际发生的动作，在新策略下比在采样它的旧策略下更可能还是更不可能？**

```text
r_t = 1.0：新旧策略对该动作看法相同
r_t = 1.2：新策略让该动作概率增加 20%
r_t = 0.7：新策略让该动作概率下降 30%
```

于是最朴素的 surrogate objective（替代目标）是：

```text
L_IS(theta) = E_t[ r_t(theta) * A_t ]
```

若 `A_t > 0`，这个动作比基线好，应增大概率，目标喜欢 `r_t` 变大；若 `A_t < 0`，动作比基线差，应降低概率，目标喜欢 `r_t` 变小。

理论上，ratio 把旧分布修正成新分布；麻烦在于，它也会把误差一起放大。当 `pi_old(a|s)` 很小、`pi_theta(a|s)` 变大时，ratio 可以非常大，少数稀有样本便统治整个 batch。无偏仍可能成立，但方差大到训练不可用。

这就是重要性采样反复出现的交换：

```text
精确纠偏  <---------------------->  可控方差
无偏但可能被极端权重支配              稳定但承认偏差
```

*结构标注：数学桥梁。ratio 把 08-12 的分布换元接进 08-16 的 on-policy 策略梯度。*

---

### 碰撞一：先别急着接受 clip

作者式主张可以压成一句：**“无偏”不是最高道德；如果无偏估计的方差让更新方向由几个极端样本决定，主动引入可控偏差反而更接近真正想优化的策略。**

你接受吗？最强反驳是：一旦允许“为了稳定而加偏差”，算法可能稳定地朝错误方向走，而且训练曲线还会显得很好看。PPO 的回应不是证明偏差无害，而是把偏差限制在一个明确局部：只有当新策略已经超出旧数据可信支持的范围时，才不再奖励它继续走远。

## 3. [骨] `min + clip` 不是把 ratio 一律夹住

PPO 的 clipped surrogate 是：

```text
L_CLIP(theta)
= E_t[ min(
    r_t(theta) * A_t,
    clip(r_t(theta), 1-epsilon, 1+epsilon) * A_t
  ) ]
```

最容易形成的误解是：“PPO 把 ratio 限制在 `[1-epsilon, 1+epsilon]`。”

不准确。代码仍可能产生范围外的 ratio；`clip` 只改变**目标函数在某些方向上的激励**。要看清它，必须把 advantage 的正负分开。

假设 `epsilon = 0.2`。

### 情况 A：`A > 0`，好动作的概率适度上升

```text
r = 1.1
原项   = 1.1 A
clip项 = 1.1 A
min    = 1.1 A
```

正常奖励：好动作更常见，目标增大。

### 情况 B：`A > 0`，好动作的概率上升过多

```text
r = 1.8
原项   = 1.8 A
clip项 = 1.2 A
min    = 1.2 A
```

超过 1.2 后不再得到额外收益。注意不是把模型概率强行改回去；只是这条样本不再鼓励它继续增大。

### 情况 C：`A < 0`，坏动作的概率适度下降

```text
r = 0.9
原项   = 0.9 A
clip项 = 0.9 A
min    = 0.9 A
```

因为 `A` 为负，`0.9A` 比 `1.0A` 更大（更少负），说明降低坏动作概率得到奖励。

### 情况 D：`A < 0`，坏动作的概率下降过多

```text
r = 0.3
原项   = 0.3 A
clip项 = 0.8 A
min    = 0.8 A
```

这里 `min` 选择更负的 `0.8A`，所以低于 0.8 后也不再得到额外收益。

四格合并：

```text
                 ratio 变小                 ratio 变大
A > 0（好动作）  变坏，不剪，继续惩罚        变好，超过 1+eps 后不再奖励
A < 0（坏动作）  变好，低于 1-eps 后不再奖励  变坏，不剪，继续惩罚
```

最关键的非对称性是：**PPO 只截断“沿 advantage 指示方向走得太远所获得的额外好处”，不会截断朝错误方向走所受的惩罚。**

所以 `min` 的作用是构造一个 pessimistic surrogate（悲观替代目标）：在“原始估计”和“截断估计”中，总取更保守的那个。

*结构标注：全文核心机制。clip 不是参数投影，也不是普遍截断梯度，而是撤销过度有利更新的边际奖励。*

## 4. [肌] 一笔 token 级的数值账

假设某 token 的旧策略概率是：

```text
pi_old(token|context) = 0.10
```

它的 advantage 为 `+2`，表示这个 token 所在动作比基线好。几轮更新后：

```text
pi_theta = 0.13
ratio    = 0.13 / 0.10 = 1.3
```

若 `epsilon = 0.2`：

```text
未截断收益 = 1.3 * 2 = 2.6
截断收益   = 1.2 * 2 = 2.4
PPO 取 min = 2.4
```

从 `0.10` 增到 `0.12` 有学习收益；继续增到 `0.13`，这条旧样本不再为额外变化买单。理由不是 `0.13` 一定错，而是：**样本是在旧策略只给 0.10 概率的世界里采到的，它没有足够证据判断新策略继续增大到哪里仍然可靠。**

这正是“旧数据发言权”的含义。clip 的边界不是关于真实最优策略的知识，而是关于当前证据覆盖范围的谦逊。

以上数值段支持第 3 节：截断发生在 likelihood ratio 所代表的相对变化上，而非绝对 token 概率上。

*结构标注：数值直觉。把抽象的局部信任范围落到一个 token 的概率搬运。*

## 5. [骨] 两种围栏：`pi_old` 的 clip 不等于 `pi_ref` 的 KL

RLHF 实现里经常同时出现两个“别走太远”，但它们防的是不同风险。

### 围栏一：PPO ratio clip，相对 `pi_old`

```text
r_t = pi_theta(a_t|s_t) / pi_old(a_t|s_t)
```

它关心的是**优化统计是否仍可信**：这批 rollout 来自 `pi_old`；更新后的策略若变化过大，旧样本就不能可靠代表它。`pi_old` 通常每轮 rollout 后刷新。

### 围栏二：KL penalty，相对 `pi_ref`

```text
beta * KL(pi_theta || pi_ref)
```

它关心的是**行为与奖励目标是否仍可信**：策略为追逐 reward model，是否离 SFT 参考模型太远，走进奖励漏洞或语言退化区域。`pi_ref` 通常长期冻结。

```text
pi_ref  ：长期语义/行为锚，防 reward hacking 与能力漂移
pi_old  ：短期采样坐标，防旧数据被过度复用
pi_theta：正在更新的策略
```

可以把它们画成两个时间尺度：

```text
长期：pi_ref ------------------------------------ 固定
          |<--------- 行为漂移预算（KL） -------->|

短期：        pi_old_1 -> pi_old_2 -> pi_old_3 ...
                 |          |          |
                 + clip     + clip     + clip
                 每批数据只支持一次局部移动
```

因此可能出现四种状态：

1. clip 很小、KL 也小：更新保守且仍贴近参考模型；
2. clip 很大、KL 小：单轮更新激进，但长期锚尚未漂远；
3. clip 小、KL 大：每轮只走小步，但积少成多已离参考模型很远；
4. clip 大、KL 也大：既在透支旧数据，也在远离长期行为锚。

PPO clip 不能替代 KL：小步走一万步仍能走得很远。KL 也不能替代 clip：最终离参考模型不远，不代表你在某一批旧数据上做的梯度估计可靠。

*结构标注：概念去混淆。把 08-13 的长期信任域与今天的短期数据可信域分开。*

---

### 旁逸：这里和数据库快照是同一个形状

一批 rollout 像数据库快照：它准确描述采样时刻的策略世界。你可以在快照上反复计算，但不能假装它自动包含更新后的世界。ratio 像把旧统计换算到新版本；clip 像版本差距过大时拒绝继续相信增量换算，要求重新抓快照。PPO 每轮重新 rollout，不是浪费，而是在刷新“事实层”。

## 6. [肌] 一批 rollout 什么时候已经被榨干

只看 loss 下降不够。更有诊断力的是一组联动信号：

```text
clip fraction   ：有多少 token/sample 的 ratio 进入截断区
approx KL       ：新旧策略平均改变了多少
ratio 分位数    ：极端权重是否集中在少数样本
entropy         ：策略是否过快收缩
explained variance：value/critic 是否能解释回报差异
reward 与 KL    ：奖励提升是否只是用更大漂移换来的
```

### clip fraction 太低

可能表示更新过小、学习率太低，或 advantage 信号太弱；数据尚未被充分利用。但也可能只是策略本来就在局部最优附近，不能机械增大学习率。

### clip fraction 太高

说明大量样本已经不再为“有利方向上的继续更新”提供梯度；继续跑 epoch 常常是在反复榨一批已经过期的数据。此时更合理的动作通常是停止本轮优化、用新策略重新 rollout，而不是把 clip 放宽。

### 平均 ratio 接近 1 仍不代表安全

少量 `0.1` 与 `1.9` 可以平均成 1。和 08-13 的“平均 KL 掩盖高漂移切片”一样，聚合会抹掉极端样本。应看分位数、按 prompt 类型/长度切片，以及正负 advantage 各自的截断率。

以上段落支持核心论点：clip 是一份数据使用合同，所以监控重点不是“有没有成功夹在范围内”，而是“还有多少数据对当前策略更新具有可信发言权”。

*结构标注：工程证据。把目标函数的局部可信性翻成可监控信号。*

## 7. [骨] 统一收口：PPO 是受限离策略学习

现在可以更精确地回答 08-16 的压力测试：“PPO 复用旧策略数据，不也违背 on-policy 吗？”

答案是：**是的，PPO 从第二步更新开始就不是严格 on-policy；它用 importance ratio 做离策略修正，再用 clip 限制修正的可信半径。**

```text
严格 on-policy：每次参数更新后立刻重采样
               统计最干净，采样成本最高

完全 off-policy：长期 replay，依靠校正或价值学习复用数据
                样本效率高，分布偏差难控

PPO：一批 on-policy rollout + 少量离策略复用
     ratio 纠偏 + clip 限制复用半径 + 重新 rollout 刷新分布
```

所以 PPO 的“proximal（近端）”不是说参数欧氏距离小，而是说**新策略在旧策略实际采到的动作上，概率比不要移动得太远**。它控制的是策略函数空间中的局部变化。

把最近几篇的链条合起来：

```text
08-12 Importance Sampling：不同分布之间如何换元，税是方差
08-13 KL Trust Region    ：奖励只能在参考模型附近被有限信任
08-14 Exposure Bias      ：条件历史错位会沿 rollout 复合
08-15 DAgger             ：让数据追上策略访问的状态
08-16 On-policy RL       ：让目标期望落在策略自己的分布
今天 PPO Clip            ：工程上无法每步重采，于是定价“旧数据还能用多久”
```

这里出现一个重要反转：PPO 不是消灭了分布错位，而是**把错位显式写成 ratio，再为可容忍的错位划定边界**。它的稳定来自承认数据会过期，而不是假装旧数据永远有效。

*结构标注：全文收口。把 PPO 定位为 on-policy 与 off-policy 之间、以偏差换方差和样本效率的局部折中。*

## 碰撞提问

这篇最想说服你接受的一个点是：**PPO clip 剪掉的不是异常梯度，而是旧策略数据对过远新策略的证据效力。**你接受吗？

压力测试：如果某个动作 advantage 为正，而且新策略确实应该把它的概率从 0.1 提到 0.9，clip 却在 ratio 约 1.2 后撤掉额外激励——这不是明知正确还阻止学习吗？

最强回应是：PPO 没有断言 0.9 错，只断言**这一批在 0.1 概率世界里采到的数据，不足以一次证明 0.9 对**。重新 rollout 后，如果该动作仍反复得到正 advantage，新的 `pi_old` 会刷新，策略可以再走一小步。clip 限制的是单批证据能推动多远，而不是长期策略能到哪里。

真正尖锐的反问因此是：如果每次 rollout 的 reward/advantage 本身带系统偏差，小步反复确认会不会只是“稳定地走向错误”？答案是会。clip 校准步长，不校准指南针；这与 08-13 的 KL 边界完全一致。

### 读后一句话（不可跳过）

> 读完这篇之后，你最想对 PPO 说的一句话是什么？

不要只复述“clip 限制 ratio”。更值得写下你的判断：为了稳定和样本效率，主动把无偏估计改成有偏估计，这在你看来是合理的统计工程，还是把问题藏进超参数 `epsilon`？

### 终局问题

> clip 用“新旧策略的概率比”判断旧数据何时失效；但如果变化集中在 rollout 没采到的动作上，ratio 根本看不见。**一个只在已采样动作上定义的局部信任域，能约束整个策略分布吗？**

这正是 sampled ratio、exact KL 与全分布约束之间的裂缝：我们通常只监控模型做过的事，却想据此推断模型所有可能会做的事。

| behavioral reference policy | 行为参考策略 `pi_old` | 生成当前 rollout 的短期策略快照 | 第 1、5 节 |
| reference policy | 参考策略 `pi_ref` | RLHF 中长期冻结的 SFT 行为锚 | 第 5 节 |
| bias-variance trade-off | 偏差-方差权衡 | clip 以可控偏差换取对极端重要性权重的方差抑制 | 第 2、7 节 |
