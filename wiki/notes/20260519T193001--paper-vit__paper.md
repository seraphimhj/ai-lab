## 问题

2020 年下半年，CV 圈有一个微妙的事实：Transformer 已经在 NLP 横扫一切——BERT、GPT-3 把架构卷成了行业标配；但在视觉里，*ResNet 仍然是 SOTA*。这不是偶然，而是有原因的。

设想一下你要做图像分类。一张 224×224 的图，最朴素的"把每个像素当 token 喂给 Transformer"是行不通的——5 万个 token 之间两两 attention，N² 复杂度直接爆显存。所以 2018-2020 年间，很多人尝试在 CNN 里"嵌"一点 attention：local self-attention 替代局部卷积；axial attention 沿着行列分别做；sparse attention 只看稀疏的几个邻居。这条路有效但*别扭*——为了让 attention 跑得动，你必须给它打上一堆"图像专用"的补丁，结果架构不再优雅，硬件加速器也不爱。

CNN 那一条路则截然不同。从 LeCun 1989 到 AlexNet 2012 到 ResNet 2015，CNN 把*三件先验*牢牢焊进了每一层：
1. *Locality（局部性）*——卷积只看一小块邻域，因为图像里语义本来就空间局部
2. *Translation equivariance（平移等变）*——同一个滤波器扫过整张图，物体挪一格输出也跟着挪一格
3. *Hierarchy（层次性）*——浅层学边缘，深层学物体，pooling 一层层抽象

这三件先验是 CNN 的天赋，也是它的*牢笼*。在中小数据量上（ImageNet 一百万张已经算"小"了），这些先验帮模型节省了海量样本——它不需要"从数据中学到平移不变性"，因为这件事被结构白送了。

ViT 作者看到的入口是这样：*这套先验真的必要吗？* NLP 里 Transformer 没有任何语言学先验——它不知道主谓宾，不知道句法树，甚至不知道相邻 token 关系比远距离更密——但只要数据够大、参数够多，它自己就能学出来这些规律。如果给 vision Transformer 喂上 NLP 级别（数亿张）的图片，它会不会也*自己学出*locality 和 hierarchy？

如果答案是 yes，那 CNN 的护城河——"图像专用先验"——就会被一个更普适的命题取代：*结构先验是数据不够时的补丁；数据足够，先验可舍。*

这就是 ViT 这篇论文的赌注。

## 翻译

回到那张 224×224 的图。ViT 的解法朴素得像个反派降智——*把图切成 16×16 的小方块，每个方块当一个词*，然后丢进一个 Vanilla Transformer encoder。就这么简单。

### 锚点：图就是一句话

把图想成一句话。一张 224×224 的图，被切成 14×14=196 个小方块，每块 16×16 像素。每个小方块经过一次线性投影（768 维），就成了一个"词向量"（patch embedding）。再加一个可学习的位置编码（learnable position embedding），告诉模型这是第几个块。开头再贴一个 BERT 风格的 `[class]` token，作为最后做分类的"汇总位"。

整张图变成 197 个 token 的序列（196 patches + 1 class token），喂给一个标准 Transformer encoder（pre-LN + MSA + MLP + 残差，没有任何 image-specific 改动）。最后取 `[class]` 那个位置的输出向量，过一个 MLP head 做分类。

这就是 ViT 的全部。整个模型唯一保留的图像先验只有两处：（a）切 patch 这一刀，告诉它哪些像素是"一个词"；（b）fine-tune 时换分辨率要对位置编码做 2D 插值。除此之外，*locality / equivariance / hierarchy 全都不再写进结构*——模型必须从数据里自己学。

### 一步步揭开：他们是怎么做到的

*第一步：架构上几乎不动*。ViT-Base 的配置直接照搬 BERT-Base：12 层、hidden=768、12 头、参数 86M。ViT-Large 24 层、307M 参数。ViT-Huge 32 层、632M 参数。patch size 用 16 或 14（命名上 ViT-L/16 = Large 用 16×16 patch，ViT-H/14 = Huge 用 14×14 patch；patch 越小、序列越长、计算越贵）。这一步的设计哲学是*能多懒就多懒*——他们就是想验证"原汁原味的 Transformer 行不行"，加任何 vision trick 都会污染实验结论。

*第二步：在 ImageNet 上先撞墙*。如果只在 ImageNet（1.3M 图）上从零训练，ViT *输给 ResNet*——通常差几个百分点。这一步本来该让人放弃。但作者反而把它当成关键证据：*ViT 输得正常*——它没有 CNN 的归纳偏置，1.3M 图根本不够它学到 locality。

*第三步：换大数据集*。
- ImageNet（1.3M 图）：ViT < ResNet
- ImageNet-21k（14M 图）：ViT ≈ ResNet
- JFT-300M（Google 内部，3 亿张）：ViT > ResNet，*而且明显胜出*

这个实验直接把"架构先验 vs 数据规模"做成了一条曲线（论文 Figure 3）：在小数据区，CNN 的先验是免费午餐；在大数据区，先验反而成了束缚——CNN 先平台期了，ViT 还在往上走。

*第四步：跨数据集迁移评测*。在 JFT-300M 预训练后迁移到下游：
- ImageNet：88.55%（ViT-H/14） vs 87.54%（BiT-L ResNet152x4） vs 88.4-88.5%（Noisy Student EfficientNet-L2）
- ImageNet-ReaL：90.72% vs 90.54%
- CIFAR-100：94.55% vs 93.51%
- VTAB（19 任务）：77.63 vs 76.29
- *预训练成本*：ViT-H/14 用 2.5k TPUv3-core-days；BiT-L 用 9.9k；Noisy Student 用 12.3k

这是论文里最锋利的一组数字——ViT 不只是赢了精度，*还省了 4x 算力*。"省算力"这件事让 ViT 从"学术好奇"变成"工业刚需"，整个 CV 圈被点燃。

*第五步：scaling 不饱和*。论文 Figure 5 把所有模型按"compute vs accuracy"画在同一张图上——ResNet 和 hybrid 已经显出曲线弯腰，ViT *仍然在线性段往上爬*。这意味着：再往大堆，回报还在。这条结论后来被 ViT-G/14（2B 参数）、SigLIP、CLIP 反复印证。

### 反直觉副发现：自注意力第一层就在做"全局卷积"

论文 Figure 7 右图最让人惊讶——他们测量了"每个 head 的平均注意距离"（mean attention distance，即一个 token attend 到的位置离自己多远）。结果：

- *最浅层（layer 0-1）*：一些 head 距离非常小（10-20 像素，相当于卷积里的小感受野），另一些 head 距离非常大（>100 像素，跨越大半张图）
- *深层*：所有 head 距离都很大，看的是全局

也就是说，*ViT 在没有任何卷积先验的情况下，自己长出了"局部 head + 全局 head 并存"的混合机制*。换句话说，CNN 的 locality 不是"必须的结构"，而是"一类有用的模式"——只要数据够，Transformer 会自动复刻它，并且*同时还学出 CNN 学不到的全局长程依赖*。·

这就是 ViT 真正的力量：它不是把 CNN 推翻，而是*把 CNN 的能力归约成自己的一个子集*。

### 还有一个漂亮的小发现：position embedding 自己学出二维拓扑

ViT 用的是 1D learnable position embedding（每个位置一个独立向量，没有任何"行/列"先验）。但训练完之后，作者拿任意一个 patch 的 PE 和所有其他 patch 的 PE 做余弦相似度（论文 Figure 7 中），发现：

- 同行的 patch 之间相似度高
- 同列的 patch 之间相似度高
- 距离越远相似度越低
- 大模型上甚至能看到 sinusoidal 结构

也就是说，*1D PE 自己学出了 2D 拓扑*。这解释了为什么作者实验里"加了 2D-aware PE 也没有提升"——因为模型不需要被告知这件事。

## 核心概念

### 概念 1：Patch Embedding（把图切碎当词用）

回到那张 224×224 的图。Patch embedding 这一步做的事是：把 14×14 网格上的每个 16×16 小方块（共 768 个像素值）展平成 768 维向量，然后过一个可学习的线性变换映射到 hidden=768 维。

实现上等价于一次 *kernel=16, stride=16, out_channels=768 的 2D 卷积*——所以工程上 ViT 的"切 patch"就是一行 nn.Conv2d。

为什么重要？这是*整个 ViT 唯一保留的图像先验*。它告诉模型："这 16×16 的像素是一组（一个语义单位），不要把它们切散"。这一点先验是必要的——如果不切 patch、把每个像素当 token，序列会长到 50K，N² attention 直接爆。Patch 这一刀的本质是*用粗粒度 token 化换序列长度，把先验降到最低限度*。

少了 patch 切分这一步，ViT 要么训不动（序列太长），要么连基本的"邻近像素是一组"都学不到——退化成 pixel-level Transformer，根本不可用。

### 概念 2：Inductive Bias 的归零（与 CNN 的本质差异）

CNN 把三件事写进结构：locality（卷积核只看邻域）、translation equivariance（同一个核扫全图）、hierarchy（多层 pooling）。ViT *把这三件全部砍掉*：MLP 层是 local 的（每个 token 独立过 FFN），但 self-attention 层是*完全 global* 的——任意 token 之间都可以直接交互，没有"邻近优先"。两层 token 之间的 2D 拓扑关系，模型必须从 position embedding 里自己学。

这是个核心设计选择，不是个组件。它直接决定了"ViT 在小数据上输 / 大数据上赢"这条曲线——*先验是补贴，不是免费午餐*；当你有足够数据，强加先验反而会限制模型表达。

少了这个"归零"动作，ViT 就退化成各种 hybrid attention（Swin、Axial、Local Attention）——能用，但不再具备"vanilla Transformer 直接搬"的简洁性，scaling law 也不会一样漂亮。

### 概念 3：JFT-300M 与"Scaling 救一切"

ViT 这篇论文真正的"必杀技"不是架构创新（架构上它故意做得最朴素），而是 *Google 内部的 JFT-300M 数据集*。3 亿张带标签的图——比 ImageNet 大 200 倍，比 ImageNet-21k 大 20 倍。

这个数据集是 ViT 能跑通的*前提条件*。没有 JFT-300M，论文的所有惊艳数字都成立不了；甚至"ViT 输给 ResNet 只是数据不够"这个论断都立不住。它在论文里扮演的角色是：*把 inductive bias vs scale 这个理论命题，做成了一条可量化的曲线*。

这点也是 ViT 的*隐性门槛*——后来开源社区在 ImageNet-21k 上复现都很吃力，因为 JFT-300M 是 Google 不公开的。一直到 LAION-5B、DataComp 这类公开大数据集出现，社区才能真正"自己重做这条曲线"。

少了这个数据集（或它的等价物），整个 ViT 的论证链就断在第三步——你根本看不到"ViT 越过 ResNet 那一刻"。

## 启发

### 在搜索推荐场景的迁移

*1. Patch tokenization 思想 → 行为序列建模*。ViT 的本质是"把连续/二维数据切成 token 序列让 Transformer 处理"。这个思想可以直接搬到推荐场景：用户的连续行为流（点击、停留、滑动）切成"行为 patch"——例如一段 10 秒的滑动+曝光+完播打包成一个 token，比单条 item-level 序列更紧凑、上下文更长。已经在做 SASRec / BERT4Rec 的，下一步是*粗粒度 patch token 化* + 长序列。

*2. Inductive bias vs scale 的权衡在搜推同样存在*。粗排里我们写了一堆"硬规则"——位置偏置修正、类目均衡、新鲜度衰减——本质都是 inductive bias，因为粗排数据稀疏、模型小。精排数据多、模型大，这些先验就开始变拖累。粗精排一致率指标（你关心的那个 Top N 召回对齐率）的瓶颈，常常出在粗排先验过强、精排已经从数据里学到更细的规律——*粗排做减法、精排做加法*这条路线，就是 ViT 给我们的同型暗示。

*3. CLS token 思想 → 召回场景的 query/doc 向量*。ViT 的 `[class]` token 是"插入一个空白汇总位让 attention 自己填"。同样思路：双塔召回里的 query/doc 向量可以不只是"序列 mean pooling"，而是插入一个可学习的 [SUMMARY] token，让模型自己决定怎么压缩——这是 CLIP / BGE-M3 已经在做的事。

### 对后续工作的辐射

这篇是 vision 现代史的*分水岭*：

- *DeiT*（Touvron 2020，Meta）：证明 ImageNet-21k 已经够用，知识蒸馏+强增广就能从 1.3M 训出好 ViT，把"必须 JFT-300M"的门槛打下来
- *Swin Transformer*（Liu 2021，MSRA）：把 locality 加回来——shifted window attention，在中小数据上更强，*同时保留 Transformer 主干*。这是 ViT 与 CNN 的"融合调和"
- *MAE*（He 2021）：mask 75% 的 patch 做重建预训练——把 BERT 的 MLM 真正搬到 vision，自监督预训练也成立
- *DINO / DINOv2*（Caron 2021，Oquab 2023）：自蒸馏 + ViT，做出业界最强通用视觉 backbone
- *CLIP / SigLIP*：把 ViT 当图像编码器、文本编码器对齐，开启多模态时代
- *MLLMs*（GPT-4V / Gemini / Claude 3）：所有现代视觉-语言大模型的 vision encoder 都是 ViT 系——*因为它和 LLM 的 token 接口天然对齐*。这才是 ViT 最深远的遗产：它把视觉变成了"一种特殊的文本"，让多模态成为自然延伸而非工程拼接

如果当年 ViT 没出现、CV 仍以 CNN 为主，今天的 GPT-4V 类模型大概率是个"CNN encoder + LLM decoder + 复杂 adapter"的拼装怪物。ViT 的真正价值，是*把视觉拉进了 token 范式*。

### 与你之前精读的三篇的关系

回看你已精读的三篇，这条线刚好闭环：

| 论文 | 时间 | 立的什么 | 与 ViT 的关系 |
|---|---|---|---|
| AlexNet | 2012 | CNN 在大数据 + GPU 上起飞 | ViT 用同一招（更大数据 + 更多算力）打回头 |
| ResNet | 2015 | 残差连接让网络深得了 | ViT 沿用 residual + LN，骨架直接套 |
| Attention Is All You Need | 2017 | Transformer 干掉 RNN | ViT 把它再搬来干 CNN |
| **ViT** | 2020 | **数据规模可以取代架构先验** | **CNN 时代的句号 / Transformer 一统的开篇** |

AlexNet 和 ResNet 教我们*怎么把视觉先验做到极致*；Transformer 教我们*怎么用通用架构 + 数据吃下一切*；ViT 是这两条路的*交汇与改道*——它说："你们 CNN 那条路走到头了，下面的路得换车。" 之后的事你都看到了：MAE、DINO、CLIP、GPT-4V，全是这趟车上下来的。

## 博导审稿

学生拿这篇论文进办公室，我的判断：

*选题眼光：strong*。"Transformer 能不能直接做 vision"这个问题在 2020 年其实已经被问烂了——很多人尝试过 hybrid，都没做出来。作者敢用最朴素的 Vanilla Transformer 直接撞，背后赌的是"NLP 的成功逻辑可以搬到 CV"——这是一个很大的赌，但赌得有理论支撑（attention 是通用的序列处理器）。命中了。

*方法成熟度：mixed*。架构上没有任何创新，"切 patch 当 token"的思路 Cordonnier 2020 已经做过 2×2 patch 的版本（论文自己也承认）。本论文的真正贡献是*scale up 到 16×16 patch + JFT-300M + 224 分辨率*。这意味着：*论文最大的工程贡献是一次极昂贵的 ablation*——在没有 Google JFT-300M 和 TPU 集群的情况下，谁也复现不了。这是个工业实验报告，不是算法发明。

*隐藏的根本预设*：论文反复说"large scale trumps inductive bias"——但这个命题有个未被讨论的假设：*预训练数据的分布要和下游任务匹配*。JFT-300M 是 Google 内部精挑的有标签自然图像，标签分布与 ImageNet/CIFAR/VTAB 高度相似。如果换成 OOD 数据（医学影像、卫星图），这条 scaling law 还成立吗？后来的 ImageNet-A / ObjectNet / 极端 OOD 评测显示——*ViT 在分布偏移下反而比 ResNet 脆弱*。这说明"先验 = 数据不够时的补丁"这个简化叙事是不完整的：先验也可能是*OOD 鲁棒性的来源*。论文回避了这个对它最具威胁的反例。

*实验诚意：strong*。Figure 3 / 4 / 5 是教科书级 scaling 实验——三种数据规模、三种模型规模、ResNet/ViT/Hybrid 三种架构。Table 2 给出公平的 compute 对比。Figure 7 的 attention distance 分析是漂亮的"机理可视化"。少数几个我会追问的点：（a）为什么 ImageNet-1k 只跑了 ResNet 风格的"标准 recipe"，没用更强的 augmentation？（b）"Hybrids 在大模型上不如纯 ViT"这一发现没有充分解释，只是 surprising 了一下。

*写作功力：好*。Figure 1 一图说尽全文方法，Section 3 简洁到没废话。Section 4.5 的 "Inspecting ViT" 把 attention distance / position embedding similarity 拿出来可视化，是这篇论文之所以经典的关键——它不只是"刷分"，还说清了"为什么有效"。

*判决：strong accept*。ICLR 2021 oral 实至名归。十年后回看，这篇会和 AlexNet / ResNet / Attention Is All You Need 并列在 deep learning 教科书第一章。它的影响不是"做出了新模型"，而是*重写了 CV 的范式*。
