# 伴读：模型会做对题，不等于它知道自己有多大把握

> 材料切面：概率预测中的 discrimination（区分/排序）、calibration（校准）与 decision utility（决策效用）。这不是一篇论文的摘要，而是把 NLL、Brier score、ECE、AUC 放回同一张评测地图。

## 全局地图

### 一句话摘要

一个模型可以很会把正例排在负例前面，却把 60% 的把握说成 99%；排序、校准、决策效用是三个不同问题，必须分别测量，再按真实代价选择阈值。

### 结构地图

```text
模型输出分数 s(x)
        |
        +--> 只看相对次序 ------> 区分/排序 ------> AUC, ranking metrics
        |
        +--> 解释成概率 p(x) ---> 概率是否可信 ----> NLL, Brier, ECE
        |
        +--> 接入行动规则 ------> 决策是否划算 ----> cost, utility, threshold

关键关系：
排序好  -X->  概率准  -X->  决策好
  ^              ^              ^
分别验证       依赖分布       依赖真实代价
```

`-X->` 表示“不自动推出”。

### 段落分类概览（Agent 判断）

- [骨] 第一单元：把“会排序”与“知道把握”拆开。
- [肌] 第二单元：用两个模型的数字例子证明 AUC 看不见置信度尺度。
- [骨] 第三单元：统一 NLL、Brier、ECE 各自在问什么。
- [骨] 第四单元：解释为什么校准仍不等于可部署。
- [肌] 第五单元：给出一套端到端评测流程。

## 逐段伴读

### 第一单元 [骨]：两个看似相同、其实不同的问题

*原句 / English anchor*

> Discrimination asks whether the model ranks positive cases above negative cases. Calibration asks whether predicted probabilities match observed frequencies.
>
> 区分能力问：模型是否把正例排在负例之上。校准能力问：模型报出的概率是否与实际发生频率相符。

*意译层（达）*

假设一个风控模型给两个人的违约分数分别是 0.9 和 0.6。若前者确实比后者更容易违约，模型的*相对判断*可能是对的。但“0.9”是否真意味着：在所有被报为 0.9 的人里，大约 90% 会违约？这是另一道题。

把分数整体做一个严格单调变换，例如把 0.9 变成 0.99、0.6 变成 0.84，样本次序完全不变，所以 AUC 不变；可是概率含义已经被改坏。AUC 只看“谁在谁前面”，不看“你把话说得多满”。

*结构标注*：核心概念切分。全文后面的所有指标都落在这条分界线上。

*概念状态判断*：最容易处在“已接受但未检验”——我们常说“模型置信度很高”，却没有先确认输出是否有资格被叫作概率。

*先问*：如果一个模型每次预测类别都对，但每次只报 0.51；另一个偶尔错，却常报 0.99，你会说谁更可靠吗？你的答案是否取决于系统要拿这个概率做什么？

### 第二单元 [肌]：AUC 完全相同，可靠性可以天差地别

有四个样本，真实标签依次为：1, 1, 0, 0。

```text
模型 A 的预测概率：0.90, 0.80, 0.20, 0.10
模型 B 的预测概率：0.60, 0.55, 0.45, 0.40
```

两者都把所有正例排在所有负例之前，因此 AUC 都是 1.0。若只看排序，它们打平。

但现在换一种真实分布：长期观察后发现，被 A 报成 0.9 的病例实际只有约 60% 发病。A 的排序可能仍然优秀，但它系统性过度自信。模型 B 若报 0.6 的病例实际也约 60% 发病，反而更校准。

反过来也成立：一个模型可以校准但排序很差。若全体人群发病率为 20%，模型对每个人都报 0.2，那么总体上它非常校准，却完全不能区分谁更危险。

*结构标注*：双向反例；证明“区分好”和“校准好”互不蕴含。

以上例子在支持第一单元的概念切分。

## 第三单元 [骨]：NLL、Brier、ECE 不是三个同义词

### 3.1 NLL：你给真实结果分了多少概率质量

*English anchor*

> A proper scoring rule rewards honest probabilities in expectation.
>
> 严格适当评分规则（proper scoring rule）在期望意义上奖励诚实地报告概率。

二分类单样本的 NLL 可以写成纯文本：

```text
NLL = -[y * log(p) + (1-y) * log(1-p)]
```

它最鲜明的性格是：*重罚自信地犯错*。真实标签为 1 时，报 p=0.9 的损失很小；报 p=0.01 的损失极大。NLL 关心完整概率分布，不只是最终选了哪个类别。

这也解释了它和最大似然的统一关系：训练时最小化 NLL，是让观测数据获得更高概率；评测时看 NLL，是检查模型在未见数据上是否仍把概率质量放对地方。原则相同，数据切分不同。

*结构标注*：把训练目标和概率评测接到同一个数学框架。

### 3.2 Brier score：概率与结果之间的平方距离

二分类形式：

```text
Brier = average((p - y)^2)
```

它也同时奖励正确性与概率诚实，但对极端错误不像 NLL 那样近乎无限惩罚。可以粗略理解为：

- NLL 对“你凭什么这么肯定”特别敏感；
- Brier 对“你的概率离结果有多远”给出平滑的平方代价。

Brier 还能分解出 calibration 与 refinement/resolution 等成分，帮助判断问题究竟是概率刻度不准，还是模型没有把不同风险人群拉开。

*结构标注*：提供第二个严格适当评分规则，并显出它和 NLL 的风险偏好差异。

### 3.3 ECE：把“报 70% 的事件是否约七成发生”做成诊断图

ECE（Expected Calibration Error，期望校准误差）通常先把预测概率分箱。例如把 0.7 到 0.8 放进一箱，再比较：

```text
该箱平均置信度 = 0.74
该箱实际正确率 = 0.66
差值              = 0.08
```

最后按各箱样本数加权平均差值。

ECE 直观，却不是 NLL/Brier 的替代品。它依赖怎样分箱：箱太少会掩盖局部失真，箱太多又会受小样本噪声影响。更危险的是，一个较低的单一 ECE 数字可能掩盖关键子群体——整体校准，不代表肿瘤亚型、语言、地区或长尾实体上也校准。

这与之前“平均如何抹掉决定性少数信号”完全同构：

```text
编码端：token -> 过早平均 -> 关键实体消失
评测端：group -> 过早平均 -> 关键失准消失
```

*结构标注*：把校准从单一分数还原为分箱与切片诊断问题。

### 碰撞

作者最想让你接受的点是：*只要输出要被当成概率使用，就不能拿 AUC 或 accuracy 代替概率评测。*

压力测试：如果有人说，“我们的系统最终只取 top-10，概率准不准无所谓，AUC/NDCG 高就够了”，这个反驳何时成立？

一个边界答案是：当下游真的只依赖稳定次序，且没有阈值拒答、资源分配、风险沟通或跨批次比较时，排序指标可能足够。但只要“0.9”会触发比“0.6”更昂贵的行动，概率刻度就重新重要。

## 第四单元 [骨]：校准好了，为什么仍不等于决策好了

*English anchor*

> Calibration is a property of predictions and outcomes; utility is a property of predictions, outcomes, and actions.
>
> 校准是预测与结果之间的性质；效用则还必须把行动纳入。

假设模型准确地预测某病概率为 10%。要不要治疗，不能由“10% 很低”直接决定，还要知道：

- 漏诊的代价是多少？
- 治疗副作用与成本是多少？
- 是否还有便宜的复检手段？
- 这个人群的基础发生率是否已经变化？

最优阈值来自行动代价，而不是从 0.5 天然掉下来。0.5 只在非常特殊的对称代价设定下才合理。

这还暴露出端到端闭环中的分布问题：一个模型在验证集上校准，部署后基础率变化，概率就可能整体偏移。排序也许没坏，概率刻度却坏了。因此校准必须回答三个限定词：*在哪个时间、哪个人群、哪种数据分布上*。

*结构标注*：从模型分数推进到真实行动，补上评测链最后一环。

*先问*：在 RAG 中，把“答案置信度低于 0.7 就拒答”写死，隐含了哪些代价假设？如果错误回答的代价因问题类型不同，统一阈值还成立吗？

## 第五单元 [肌]：一套不会被单指标骗过的评测顺序

```text
1. 先定义行动
   输出用于排序、阈值触发、拒答，还是概率沟通？

2. 再测区分
   AUC / PR-AUC / Recall@K / NDCG
   问：能否把更可能的正例排在前面？

3. 再测概率质量
   NLL + Brier
   问：概率质量是否放对，是否自信地犯错？

4. 展开校准诊断
   reliability diagram + ECE
   问：失真发生在哪个置信区间？

5. 做关键切片
   时间、人群、语言、领域、长尾实体、难度
   问：整体平均掩盖了谁？

6. 接入真实代价
   cost curve / expected utility / abstention curve
   问：在可行动的阈值上，系统是否真的更好？

7. 上线后重验
   监控基础率、输入漂移、校准漂移
```

*结构标注*：把概念落到端到端评测程序；前四步评模型，后三步评系统。

## 全文复盘

### 理解轨迹

```text
“模型准不准？”
      |
      +--> 排得对吗？ -------- 区分
      |
      +--> 概率说得准吗？ ---- 校准
      |
      +--> 错得有多自信？ ---- NLL / Brier
      |
      +--> 行动后划算吗？ ---- 决策效用
      |
      +--> 换人群还成立吗？ -- 分布与切片
```

今天真正要拆掉的，是把一个模型压成一个“准确率”的习惯。模型不是一个分数，而是一条从预测、概率、阈值到行动的链。

### 读后一句话（不可跳过）

读完后，最想对这套评测框架说的一句话是什么？不要复述定义；试着指出你当前系统中*最可能把排序分数误当概率*的那个位置。

### 终局问题

如果后处理温度缩放能让 NLL/ECE 明显变好，却完全不改变样本排序，那么“模型变好了”究竟是什么意思：知识变多了、表达更诚实了，还是只学会了更合适地下注？这三种改进在产品决策中值同样多的钱吗？

### 下一步线索

沿今天的终局问题继续，最直接的一步不是再看一个指标，而是读 Guo et al., *On Calibration of Modern Neural Networks*（ICML 2017）中 *temperature scaling* 一节：它展示了为什么只调一个温度参数、完全不改变 argmax 与排序，也能显著修复概率刻度。读时只盯一个问题：它修的是模型的“知识”，还是模型表达把握的“刻度”？
